## 📖 About

PVP Timer Mod tracks combat tag timers, cooldowns, and pearl timers in a clean HUD, keeping you aware of every competitive timing during server PVP.

---

## ✨ Features
<a name="features"></a>

- **Combat Tag Timer** — counts down your server combat tag.
- **Pearl Cooldown** — Ender Pearl throw cooldown displayed.
- **Totem Counter** — tracks totems consumed this session.
- **Pot Tracker** — splash potion timing aid.
- **Fireball Cooldown** — ghast fireball and crystal timing.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
